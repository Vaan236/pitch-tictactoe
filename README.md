# Pitch Tic-Tac-Toe

A responsive, soccer-themed Tic-Tac-Toe web application built with React, Next.js (App Router), TypeScript, and Tailwind CSS for the SUpost Junior Developer challenge.

## Features

- Two-player turn-based gameplay (Striker vs. Keeper) on a 3x3 board
- Win detection with highlighted winning cells, draw detection, and game reset
- Persistent match scoreboard tracking wins and draws
- Responsive mobile-first layout with custom SVG pitch background and win celebrations

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Running Locally

```bash
npm install
npm run dev
